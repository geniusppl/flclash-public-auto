# flclash-public-auto

Public-node FlClash config, auto-built hourly by GitHub Actions from
`Hidashimora/free-vpn-anti-rkn` 29.txt (the pool that worked on the user's phone;
1.1 did not).

After this repo is created on GitHub, the subscription link is:

```
https://cdn.jsdelivr.net/gh/<OWNER>/<REPO>@main/flclash.yaml
```

Replace `<OWNER>/<REPO>` with the real repo path. Import that URL in FlClash
as a remote config; updating it pulls the latest built file. No private
credentials are in this repo — only public nodes.
